CPU-only source plan for preserving the new prefill and selecting the existing original-Q4 decoder

The smallest composition starts from the HC-v3/QSA-packed-V worker and changes phase routing, original weight ownership, the F32 cache inventory, persistent residency selection, and immutable identity/status. It retains all current prefill kernels and arithmetic. It is a new numerical derivative: the old ~80 tok/s result cannot be inherited because the prefill state controls subsequent target logits, MTP acceptance, and semantic behavior. No binary has been built and no GPU or model payload has been accessed for this plan.

The source bases are `build/prefill-hc-inject-norm-sep21-worker-v3`, `build/hybrid-sg2-tail-fma-sep21-worker-v1`, and the actual pruned build `build/dense-w8a8-residency-prune-sep21-worker-v1`. `source-plan-v1.json` records source SHA256 pins and the saved owner census. The prospective QSA composition adds its own closure and resource plan after root integration.
