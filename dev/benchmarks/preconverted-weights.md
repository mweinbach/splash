# Local preconverted INT8 weights

The validated hybrid model uses 64 converted target MLP-down projections. The
other projections keep their original Q4/Q8/BF16 representation. These local
artifacts persist the exact INT8 codes and F32 row scales already generated by
the production loader; they do not quantize the model a second time.

Build and generate once with the production loader:

```sh
make BUILD=build/prequantized build/prequantized/engine-tests/preconvert-weights
SPLASH_INT8_POLICY=hybrid build/prequantized/engine-tests/preconvert-weights \
  build/prequantized/splash.metallib install/models/incoai/Qwen3.8-27B-Splash \
  install/preconverted/Qwen3.8-27B-Splash-hybrid-v2 write build/weights-write.json
```

Audit the saved format with strict read mode:

```sh
SPLASH_INT8_POLICY=hybrid build/prequantized/engine-tests/preconvert-weights \
  build/prequantized/splash.metallib install/models/incoai/Qwen3.8-27B-Splash \
  install/preconverted/Qwen3.8-27B-Splash-hybrid-v2 read build/weights-read.json
```

Use it for a separate server:

```sh
SPLASH_PRECONVERTED_INT8_DIR="$PWD/install/preconverted/Qwen3.8-27B-Splash-hybrid-v2" \
SPLASH_PRECONVERTED_INT8_MODE=read \
splash serve --model incoai/Qwen3.8-27B-Splash --port 8011 --no-webui
```

With a directory configured, mode defaults to `read`. `off` preserves startup
conversion; `write` converts and atomically publishes immutable artifacts. Read
mode requires every eligible artifact and never falls back to conversion. Keys
include schema/converter, dimensions, frozen precision policy/role/kind and an
exact digest of the original packed Q4/scales/biases. Metadata and actual payload
hashes, signed-code range, finite positive scales and canonical padding are
checked before Metal use. Missing, stale, truncated or corrupt files fail clearly.

The original downloaded checkpoint remains untouched. The derivative directory
is local and git-ignored. One payload mmap contains both codes and scales, with
page-aligned sections and the same physical allocation footprint as the two
normal converted planes. Read-only MAP_SHARED ownership is retained by Metal
buffers. Hybrid GPU-residency allocation count changes from 201 to 137 because
the two coefficient views now share one backing per projection.

The `read` report must show zero `converted_projections` and 64
`preconverted_projections` for this 27B/hybrid model. Payload byte counters are
logical code+scale bytes; disk storage includes page padding and metadata.
Fingerprint parity verifies that cache precision/content identity is unchanged.

Saving weights removes repeated startup reconstruction/requantization. Actual
integrity checking and disk access still cost time, so compare total loader
latency against `off` rather than claiming the conversion time is a net speedup.
Activations are request/token dependent; they still require runtime quantization.
Any producer fusion must preserve dynamic maxima, BF16 rounding, code/scales and
prefill/decode/replay behavior.

On this Mac, the local `splash` wrapper now selects the saved 27B derivative in
strict read mode when the hybrid policy is used and no artifact override is set.
Other model IDs and policies keep their previous behavior. Explicit
`SPLASH_PRECONVERTED_INT8_MODE=off` returns to startup conversion. The live default
was verified with 64 cached projections and zero conversions, matching model
fingerprints and correct JSON output.

Measured whole-loader off/read/read/off times after validation overlap were
2.892/2.952/2.955/2.924 seconds. Saved weights remove the quantizer, while full
validation leaves total loading near break-even. A separate 48-request native
HTTP comparison had exact paired outputs and approximately unchanged throughput.
The exact producer-peak activation-fusion prototype showed no reliable net speed
improvement and was not enabled.
