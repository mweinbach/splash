# Root-owned exact trunk prefill comparison

This oracle proves **TRUNKPREF only** for the sealed teacher-v5 and phase-v5 workers. The teacher exporter and phase comparator are separately linked executables, run in separate processes, each with one Metal backend lifetime. No trained MTP head is constructed: teacher prime, its five cache planes, decode, verification, service transport, and performance are outside this proof.

The prepared Root entry points are:

```sh
build/trunkpref-exact-teacher-sep22-v3/run-root-export.sh
build/trunkpref-exact-phase-sep22-v6/run-root-compare.sh
```

Run the comparator only after the exporter exits successfully. Its launcher checks the completed export report and backend-destroyed marker, command and runner seals, and the manifest/argv/environment role pairing. Each launcher clears inherited `SPLASH_FLASH_*` settings and applies the explicit command environment. The command JSON and ready seal pin the oracle, its own worker closure, and the exact loaded metallib. The already-running teacher exporter retains its original inspected launcher and artifact pins. Root must own the GPU for both commands.

The completed parent export remains in `build/release/flash/sep22-trunkpref-export-v1`. Comparator v2 stopped before byte comparison because the diagnostic reservation omitted the 1,890,975,744-byte Dense W8 coefficient cache. Accounting-fixed v4 passed its guards, then found a genuine R16 hidden mismatch. The phase worker v5 restores the original 508-prefix selector membership, including generic HC Prefill context, without restoring unused F32 backing. The final comparator v6 pins that worker and writes fresh `sep22-trunkpref-compare-v4.json`, retaining the exact cache reservation and all allocation guards. See `ALLOCATION_FIX_REVIEW.md` and `R16_FAILURE_REVIEW.md` for the distinct source findings.

Both processes read and hash the canonical 2048-token fixture themselves. Its preexisting source certificate binds file SHA `4985e55294b83c72cb9e51e00c40f918460b6c4f560cb5b32d4be3662e540b57` and packed U32 SHA `0a383d21f5c784b0616d589847ca6cb04c69bf654729f2344e2b916e542f36b4`. Preparation never reads the fixture or model payload.

The native schedule uses `forward()` exclusively. Each of seven cases creates its own fresh capacity-4096 state and runs the canonical 2048-token body with all hidden rows and last-row logits. Six cases append physical R1/4/8/9/15/16 using the corresponding first rows of the canonical final 16 tokens. Every case then appends the canonical first eight tokens as future Prefill, before any Decode. Tiny appends return all real logits and complete compact GPU greedy records. The repeated bodies must also match the original body checkpoint exactly.

Every completed checkpoint saves separate state and output frames. State frames include all 134 physical request buffers, valid extents separately, length/capacity/poison/pending/local-owner predicates, and scalar layer geometry. Comparison includes inactive QSA suffixes, incomplete pooled blocks, allocation padding, and complete GDN/PLE buffers. Owner and identity addresses are checked for stability within each process and are omitted from cross-process frames.

Output frames include every consumed hidden row, every returned BF16 vocabulary row, and the full 16-byte greedy records. Results are serialized immediately, before another trunk call can reuse borrowed scratch. Numeric output/state words must be finite. The comparator uses direct streaming byte comparisons; hashes provide provenance and do not replace `memcmp`. Exact frame length, declarations, truncation, and trailing bytes are hard gates.

On failure, the normal success report is absent. Native `.failure.json` records the stage, completed and pending frame labels/counters, current frame/section/plane, absolute and relative offset, word width, allocation/governor data and teardown state. Root-runtime mismatches also record the differing byte values. Publication errors have bounded JSON on stderr. The launcher publishes a separate `.launcher-failure.json` for preflight, launch, unsuccessful exit and signals, preserving the native report and explicitly leaving backend state unknown if no native report exists. Its failure destination is baked into the frozen runner instead of obtained from an unchecked command document.

`frame_headers.py` reads only bounded framing metadata with unbuffered FileIO and seeks over every tensor payload. It neither reads nor hashes tensor bytes. For Root metadata inspection, use the frozen `build/trunkpref-exact-phase-sep22-v6/frame_headers.py` with a frame and optional `--offset 153`. Its synthetic read trap verifies that byte 153 in the R16 output frame is the first hidden BF16 payload byte.

There are 14 state/output checkpoints, 28 unique frames, and 12 repeated-body frame comparisons. The aggregate spill is capped before writes at 4 GiB; the CPU bound is 3,448,394,112 bytes. Only one request exists at a time. The phase comparator obtains its own diagnostic reservation, verifies the actual workspace and one-state arena against the plan, commits the reservation, and records a final governor snapshot. It does not request the Worker's saved/composite residency lease, so its memory telemetry does not qualify service residency or sustained fit. The teacher exporter records its diagnostic reservation/peak without the newer comparator's commit/snapshot checks. The phase process additionally requires exactly 960 I8 Prefill graph calls and 693,360 encoded rows, with zero Q4 Prefill and zero Decode/Verify graphs.

Model source/manifest identity, the unchanged Full512 I8 numerical/store identity, canonical input hashes, and all common numeric Prefill flags must match before the first phase trunk call. Different phase global identity, F32 cache census, kernel-route string, resource ledger, and compiled owner are recorded separately. This tests the parent's 508-entry versus phase's 296-entry F32 cache through real tiny Prefill outputs and carried state, rather than assuming cache census equivalence.

`build.py` verifies the corresponding immutable worker CPU seal and copies only that worker's effective closure. It excludes the sole Worker object containing `main`, retains Forward and `teacher_bulk`, checks normalized object uniqueness, and links all 53 nonworker objects. Existing RequestState friendship means no header edits or header-consumer rebuilds. The diagnostic preserves timing ABI 200 and compiles against its copied source roots. It opens no port and uses no Worker frames, so this is separate from service lifecycle qualification.

CPU tests cover streaming parity across the 1 MiB boundary, a last-byte mismatch, extent rejection, finite gates, endianness, the 134-plane physical admission formula, and the spill limit. They construct no backend and read no model payload. Failed initial compiler snapshots are retained separately; only the ready seals above identify reviewable artifacts.
