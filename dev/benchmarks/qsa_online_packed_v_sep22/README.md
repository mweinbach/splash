This private standalone component retains the current parent's original ONLINE
QSA arithmetic. It changes only three global value-cache address expressions
and adds a 2 MiB `ushort` bit transpose. Original caches remain unchanged.

The original early/temporal/reducer AIR is the performance control. Private
native aliases and same-SSA reducer taps authenticate arithmetic outside timing.
Exact F32 statistics, numerators and quotient, rounded and gated BF16, original
diagnostics, physical cache planes, and causal replay after future appends must
pass before the inclusive original-three versus pack-plus-three timing block.
Both variants receive at least 150 ms GPU warm work and 18 balanced pairs.
CPU buffer access is excluded from that block.

HostV3 accounts for native owners and CPU snapshot vectors separately. The
component admits a 1 GiB native ceiling and a separate 512 MiB host allowance
before fixture reads or allocation, with a 1.5 GiB combined component ceiling.
The engine governor keeps its existing physical-memory-minus-system-reserve
limit and normal pressure/growth checks. Both tagged reservations remain held
until all private owners and vectors are destroyed; zero reservations and
owned buffers, stop, and backend destruction precede success publication.

CPU preparation reads program artifacts and the explicitly authorized small
capture manifest only. GPU execution and all operand loading belong to Root.
The real fixture is an older B4 lane0 layer3 projection capture, not the current
canonical B1 benchmark. This component does not qualify model trajectory,
whole-model throughput, or production promotion.
